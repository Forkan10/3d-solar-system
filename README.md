# 🌌 3D Solar System with Hand Gesture Tracking

An interactive, browser-based 3D Solar System simulation created with **Three.js** and powered by **Google MediaPipe Hands** for real-time webcam gesture control.

## 🚀 Features
- **3D Solar System**: Realistically scaled planetary orbits, lighting, shadows, and Saturn's rings.
- **Hand Gesture Control**:
  - 🖐️ **Open Hand & Move**: Rotate the solar system smoothly in 3D space.
  - 🤏 **Pinch (Thumb & Index) & Move Up/Down**: Zoom in and out.
- **Mouse & Touch Support**: Left-click and drag to rotate, scroll wheel or pinch on touchscreen to zoom.
- **Privacy & Safety First**: 100% client-side execution. No server-side video streaming or data collection.

## 🛠️ Tech Stack
- [Three.js](https://threejs.org/)
- [MediaPipe Hands](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker)
- HTML5, CSS3, JavaScript (Vanilla)
